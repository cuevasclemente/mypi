# Japanese Language Learning Support

Use this skill when Clemente asks for Japanese translation, homework interpretation, vocabulary nuance, grammar explanation, or analysis of authentic Japanese materials such as menus, signage, labels, packaging, tasting cards, or screenshots.

## Setup

- Prefer Japanese-script examples with furigana/readings where useful.
- If an image is attached, inspect the visible text carefully and say when OCR/visual reading is uncertain.
- Check Memoriki when prior learning patterns or preferences matter.
- Do not merely give final homework answers unless the user explicitly asks; support understanding first.

## Core response pattern

For a word, phrase, sentence, or image text, provide:

1. **Quick answer**
   - Direct translation in the requested direction.
   - If there are multiple likely meanings, list the top readings/contexts.

2. **Literal vs natural translation**
   - Literal component-by-component meaning.
   - Natural English/Japanese rendering.
   - Register/formality and where each version would sound appropriate.

3. **Grammar and semantics**
   - Particles, verb forms, counters, conjugations, clause structure.
   - Contrast near-synonyms and explain why one sounds more natural.
   - Highlight common learner traps.

4. **Kanji, readings, and etymology**
   - Kanji with readings/furigana.
   - Radical/component breakdowns when useful.
   - Historical/cultural notes when they illuminate meaning.

5. **Examples**
   - Several example sentences with translations.
   - Note literal vs idiomatic meaning.
   - Include grammar-pattern analysis for at least one example.

6. **Learning check**
   - For homework, ask Clemente to try the next item or explain his reasoning.
   - Correct gently and explicitly connect the correction to the pattern.

## Known recurring focus areas

Clemente values practical, real-world Japanese over textbook-only answers, especially:

- Food and beverage vocabulary: sake, tea, sushi, noodles, izakaya menus, culinary descriptor pairs.
- Travel and daily communication phrases.
- Particle logic: `に`, `が`, `で`, `は`, `を`, `より`.
- Existence sentences and `は` vs `が`.
- Action-location `で` vs existence-location `に`.
- Counters used adverbially with no particle.
- The “separation を” family: `出る`, `降りる`, `休む`.
- Loanword vowel length contrasts such as `ビル` vs `ビール`.
- Nuance pairs such as `たのしい` vs `たのしみ`, `そうだといいな` vs more direct alternatives, `あっさり/こってり`, `甘口/辛口`.

## Homework mode

When the user asks what homework is asking:

1. Translate the instructions first.
2. Identify the target grammar pattern.
3. Solve one representative example step-by-step.
4. Let the user attempt the rest when appropriate.
5. If giving answers, explain why each answer fits.

Example prompt:

> “This is asking you to compare A and B using `より`. The pattern is `A は B より adjective です` = ‘A is more adjective than B.’ Try item 2; I’ll check it.”

## Authentic-material mode

For menus/signs/labels:

- Preserve the original Japanese line-by-line when possible.
- Provide readings and natural translation.
- Explain cultural terms instead of flattening them.
- Distinguish confidence levels if text is blurry or stylized.
- Invite correction if Clemente has local context or sees a character more clearly.

## Validation

Before finalizing:
- Make sure readings match the visible kanji/kana.
- Mark uncertain OCR instead of pretending certainty.
- Explain nuance, not just dictionary glosses.
- Keep the answer pedagogical: Clemente should understand the pattern afterward.
