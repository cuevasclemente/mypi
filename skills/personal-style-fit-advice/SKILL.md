# Personal Style & Fit Advice

## Setup

- Use when Clemente asks about clothing, outfits, colors, silhouettes, tailoring, fit photos, or whether to buy/keep/return a fashion item.
- If the answer depends on Clemente's existing wardrobe, preferences, or past decisions, check Memoriki first:
  - Wiki: `~/src/memoriki/memoriki/wiki/entities/clemente-profile.md` and related style pages if present.
  - MemPalace: search for prior style, wardrobe, and purchase context.
- If Clemente names a specific SKU/model/brand, verify current product details from authoritative sources when possible before asserting materials, cut, weight, price, or availability.
- Treat uploaded photos as privacy-sensitive personal context. Discuss only visible fit/style factors relevant to the question; do not infer sensitive traits.

## Core Workflow

1. **Clarify the decision frame**
   - Is Clemente choosing between options, checking fit, planning an outfit, deciding whether to buy/return, or exploring identity/taste?
   - Ask if the goal is practical versatility, a specific occasion, climate comfort, wardrobe gap-filling, or deliberate self-expression.

2. **Load personal context when useful**
   - Look for durable wardrobe facts: recurring colors, existing outerwear/shoes/bags, recent purchases, known gaps, climate/relocation context, and prior style conclusions.
   - Use that context explicitly: “this repeats your warm/earthy palette” vs. “this adds a missing contrast/edge slot.”

3. **Evaluate photos with uncertainty**
   - Note limitations from lighting, angle, mirror distortion, pose, and phone lens.
   - Evaluate concrete visual cues:
     - shoulders: seam placement, excess fabric, pulling
     - torso: drape, taper, bunching, zip/button strain
     - length: hem relative to belt/hips, sleeve break
     - color: contrast with complexion, hair, glasses, jeans/shoes, and common shirts
     - silhouette: whether it reads intentional, costume-y, too formal/casual, or duplicative
   - If photos are missing or uploads fail, say so and ask for re-upload rather than guessing.

4. **Separate “looks best” from “does the job”**
   - Make the distinction explicit:
     - **Objective flattery/fit:** which option looks more harmonious, proportional, or versatile.
     - **Wardrobe role:** what gap the piece fills and whether it duplicates existing items.
     - **Aspirational/taste goal:** what version of Clemente the item helps him access.
   - Do not reduce taste questions to consensus or generic versatility. If the safer option leaves him flat and the contested option keeps pulling, treat that pull as decision data.

5. **Give a decision, not just pros/cons**
   - Clemente often wants honest pushback. State the recommendation and why.
   - Include failure modes: costume risk, closet orphan risk, climate impracticality, over-duplication, or poor fit.
   - Suggest a small validation step when appropriate: try both options with the same jeans/shoes/shirt, sit/raise arms, check in daylight, or compare against the intended use case.

6. **Offer memory capture for durable conclusions**
   - If the session reveals a durable style preference or purchase decision, ask before recording it.
   - Good memory candidates: purchased item, recurring wardrobe palette, successful silhouettes, “contrast slot” decisions, fit sizes, or meta-lessons about taste.
   - Do not record one-off uncertainty or unconfirmed impressions.

## Concrete Examples

### Brown vs. black leather jacket

Use a layered recommendation:

- Brown may be warmer, softer, easier with an earthy wardrobe, and better for daytime fall/winter outfits.
- Black may be the better acquisition if the closet already skews brown/olive/honey/natural and the desired role is evening edge or deliberate contrast.
- If Clemente says he wants the piece to expand him rather than confirm his existing style, weight that heavily.

Example phrasing:

> Brown is the better match; black is the better acquisition. If this jacket is supposed to add the missing edge/contrast register, choose black even if brown wins the generic harmony test.

### Leather jacket silhouettes

Compare silhouette signals and use cases:

- Café racer / stand collar: minimal, adult, night-out, lower costume risk.
- Double rider / Perfecto: iconic, aggressive, higher expression and higher costume risk.
- A-2 / flight jacket: heritage, friendlier, often more casual/daytime.
- Trucker: workwear/casual, may duplicate existing chore/trucker energy.
- Car coat / leather overshirt: refined or fashion-y, but a different wardrobe gap.

### T-shirt colors for try-on tests

Recommend controlling variables:

- Use the same jeans, shoes, and shirt for both jackets.
- Start with white/ecru or heather gray to reveal jacket color and silhouette cleanly.
- Add one realistic wardrobe shirt, such as navy/black/olive, to test actual wearability.

## Validation Checklist

Before finalizing advice, confirm:

- [ ] Did I check Memoriki/MemPalace if personal wardrobe context matters?
- [ ] Did I verify named product specs if I cited factual details?
- [ ] Did I separate fit/flattery from wardrobe role and identity/taste goals?
- [ ] Did I state uncertainty from photos instead of overclaiming?
- [ ] Did I give an actionable recommendation or next try-on step?
- [ ] Did I ask permission before recording durable style conclusions?
